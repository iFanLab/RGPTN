# RGPTN: Learning on Graphs, Hypergraphs, and Heterogeneous Graphs with Noisy Labels

This repository provides the official implementation of **RGPTN**, a robust graph learning framework introduced in our paper *"[RGPTN: Learning on graphs, hypergraphs, and heterogeneous graphs with noisy labels](https://www.sciencedirect.com/science/article/pii/S0950705126015881)"*.

## Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:iFanLab/RGPTN.git
   cd RGPTN
   ```
2. Set up the environment:
    ```bash
    conda env create -f env.yaml
    ```

## Usage

To quickly run a demo with the default configuration, simply execute:
```bash
bash train.sh
```
